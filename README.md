# Harish K — Portfolio Website
Link to Profile : https://marvelous-starburst-5d1880.netlify.app
A responsive, static portfolio website based on the details in Harish K's resume.

## Files
- `index.html` — page content
- `styles.css` — responsive design and visual styling
- `script.js` — mobile navigation, reveal animations, active navigation, and email form
- `assets/profile-photo.jpg` — add your own profile photo here

## Add your photo
1. Create/open the `assets` folder.
2. Copy your photo into it.
3. Rename the photo to `profile-photo.jpg`.
4. Refresh the page. For best results, use a clear portrait photo.

## Run locally
Open `index.html` in a modern browser. For a local development server, use VS Code's Live Server extension.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `harish-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will be shown in Settings → Pages.

## Before publishing
- Add your photo as `assets/profile-photo.jpg`.
- Add your actual LinkedIn URL in `index.html` if you want it displayed. A LinkedIn URL was not supplied, so no fake link is included.
- Confirm project repository URLs and personal details.
- Email links and the contact form open Gmail compose in a new browser tab. The contact form does not submit to a server; the visitor must send the email from Gmail.
- This is a static site, so it does not require Firebase configuration. You can host it on GitHub Pages or another static hosting provider.
